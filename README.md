# DesAIgn

> 🚧 **Work in Progress**
>
> DesAIgn is currently under active development. Features, UI, and AI behavior may change.

DesAIgn is an AI-powered UI/UX wireframing tool that transforms natural-language prompts into generated website designs.

## Current Features

- AI-generated website designs from text prompts
- Support for vague, short, and typo-heavy prompts
- AI-assisted design editing
- Preservation of the original design intent during edits
- Dynamic React and Tailwind rendering
- JPG and PDF export

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Groq API
- Qwen / GPT-OSS
